# Test fixtures

Generated by `generate.sh` (needs `ffmpeg` with `libx264` and `aac`, plus `python3`). Re-run it from
any directory to rebuild every fixture:

```bash
tests/data/generate.sh
```

Set `GAV_FIXTURE_FONT` to use a different TTF than DejaVu Serif Bold (Bitstream Vera/DejaVu
licence, redistributable).

| File | Contents |
|------|----------|
| `multi.mkv` | 30 s, 320×240, 25 fps CFR; audio `eng` (440 Hz) and `jpn` (880 Hz); ASS track "Signs" (`eng`) using an attached DejaVu Serif Bold font; chapters One (0–10 s), Two (10–20 s), Three (20–30 s) |
| `multi.en.srt` | UTF-8 sidecar, two cues |
| `multi.fr.srt` | Windows-1252 sidecar with accented characters, CRLF line endings |
| `styled.ass` | 1280×720 script: positioned sign (3–8 s), rotated sign (10–15 s), karaoke line (18–23 s) |
| `styled.mp4` | 25 s, 1280×720 dark background for `styled.ass` |
| `playlist-relative.m3u8` | Two relative entries and one missing entry |
| `corrupt.mkv` | First 64 bytes of `multi.mkv` |

`long.mp4` for the resume scenarios in `quickstart.md` is not committed. Create it locally with:

```bash
ffmpeg -f lavfi -i "testsrc=size=640x360:rate=25:duration=1800" -c:v libx264 -preset ultrafast -crf 40 long.mp4
```
